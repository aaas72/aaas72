## About Me

I'm a full-stack engineer who designs and ships complete products — from the database schema and API to a polished, accessible interface. I care about clean architecture, security, and interfaces that feel effortless to use.

- **Focus:** production-grade web platforms with TypeScript, Next.js, NestJS and Node.js
- **Also build with:** ASP.NET Core, Python (FastAPI), Flutter and React Native
- **AI work:** skill-matching engines with NLP embeddings, on-device vision with YOLO, LLM-backed document analysis
- **Ship it right:** Docker, Nginx, CI with GitHub Actions, multilingual (AR / EN / TR) and RTL-ready UIs
- **Languages:** Arabic · English · Turkish
